# IncogPrio

A browser extension to **mask student numbers and priorities** in CRS, allowing you to conceal them in public (for privacy purposes).

![](sample.png)

## Browser Support 

- Chrome/Chromium (Chrome browsers)
- Firefox/Zen (Gecko browsers)

## Installation

1. Install this Github repo

### Chrome (Chromium browsers)

2. Go to `chrome://extensions`
3. Select `Load unpacked` and look for the `chromium` folder from this Github repo

### Firefox (Gecko browsers)

2. Allow unsigned extensions by `about:config` -> `xpinstall.signatures.required : false`
3. Go to `about:addons`, click the "Settings" button (the gear symbol), and click `Install add-on from file`
4. Find and click `incogprio.xpi` from `firefox` folder

Installation done! Try it out in UPD CRS!

## Limitations

Not all student number instances are redacted as of now, only the ones in the sticky top bar, preenlistment, and home page.

## Disclaimers

The effects are purely visual (for privacy purposes). This does *not* change your true priority.

Also, check your real prio from time to time by unmasking priority occasionally, just so you can check if it changed :D
